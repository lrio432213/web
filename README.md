# 云间 CLOUDROOM

一间城市高空的复式小屋。以参考图中的双层落地窗、夹层卧室、柔软米色沙发和冷暖灯光为灵感，使用 Three.js + CSS + GLSL 原创搭建。

## 直接打开

双击 **index.html**，使用支持 WebGL 2 的 Edge / Chrome 打开。约 1 MB，Three.js、模型、程序纹理、天空、城市和后期处理全部内置；无需联网、无需安装依赖、无需启动服务器。

## 操作

| 功能 | 操作 |
| --- | --- |
| 白昼 / 夜幕 | 右上角氛围面板，或 N |
| 薄雾 / 晴朗 | 城市薄雾开关，或 F |
| 自由观景 | 拖动旋转，滚轮缩放，右键拖动平移 |
| 第一 / 第三人称 | 底部视角按钮，或 1 / 2 / 3 |
| 步行 | W A S D / 方向键；Shift 慢跑 |
| 环顾 | 拖动画面；或点“点击开始漫游”后移动鼠标，Esc 释放 |
| 上二楼 | 走到后方木楼梯左端，沿楼梯向右上行 |
| 换视角 | 第一与第三人称之间保留所在位置 |
| 固定机位 | 左侧客厅、窗边、卧室、全景 |
| 镜头漫游 | 右上角开启；拖动可接管 |
| 沉浸模式 | H 隐藏 / 显示界面 |
| 保存画面 | 右上角相机，导出不含界面的 PNG |
| 环境声音 | 右上角声音按钮，默认关闭 |
| 手机 / 平板 | 单指旋转、双指缩放；步行时屏幕方向键移动、拖动环顾 |

小屏幕的氛围面板由右上角太阳图标展开。建议先在桌面浏览器全屏体验；画质可选“流畅 / 精致 / 极致”。性能取决于设备、浏览器和窗口分辨率。

## 场景内容

两层复式结构与玻璃护栏、可行走楼梯、客厅、阅读椅、餐桌、厨房、卧室和书桌。木地板、织物、地毯、窗帘、书籍、装饰画、绿植均由代码生成。窗外是有视差的三维城市；窗灯、天空和雾在昼夜之间平滑变化。雾作用于室外，室内保持清晰。

采用物理材质、实时阴影、接地阴影、SSAO、克制的 Bloom、ACES 色调映射、SMAA 抗锯齿和轻微胶片颗粒。第三人称包含步行动画、室内边界、家具碰撞、楼梯高度与跟随镜头避让。

## 编辑与重新打包

```sh
npm install
npm run build
```

编辑 `src/main.js`（模型、材质、光照、交互）、`style.css`（界面）、`index.template.html`（结构）。构建会同时更新根目录和 `dist/` 中的 `index.html`。打包后的 HTML 可单独复制到任何位置。

开发预览：`npm run dev`，访问 `http://127.0.0.1:4173`。

本项目使用 Three.js 0.186.0，第三方授权见 `THIRD_PARTY_NOTICES.md`。没有使用外部模型、照片、在线字体或收费素材。
